# my-dsh-skills

DSH (DeepSeek Harness) 技能集合仓库。

## Skills 列表

- [wecom-dsh-bridge](skills/wecom-dsh-bridge/) — 企业微信智能机器人联通 DSH，实现在企业微信里与 AI 自然对话、并让 AI 控制这台电脑（执行命令）。

## 使用方式

把某个 skill 目录（含 SKILL.md）交给 DSH，DSH 会按 SKILL.md 的步骤指导用户完成配置。每个 skill 目录内附带的代码/模板/脚本均可直接使用。
